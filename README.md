# Daily Attendance + OT Tracker (Mobile App)

## Live App (GitHub Pages)
After enabling Pages, open:
**https://santhakumaremf-cpu.github.io/daily-attendance-ot/**

## How to use on Phone
1. Open the link above in Chrome / Safari
2. Browser menu → **Add to Home Screen** / **Install App**
3. App icon will appear on home screen — use like a normal app

## Features
- Employee add / select
- Daily Check-in & Check-out
- Automatic working hours + OT calculation (after 8 hrs)
- Today summary
- Filter by employee & month
- Monthly report
- Export CSV
- Dark mode
- Data stored in phone (localStorage)

## OT Rule
- 8 hours = Normal
- Above 8 hours = Overtime (OT)
